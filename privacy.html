Privacy Policy

Last updated: October 26, 2026

Purpose

This is a personal, non-commercial OAuth application used to connect a private Home Assistant installation with Google services, including Google Drive.

Google Account Data

Google account access is granted only after explicit authorization by the account owner through OAuth 2.0. Access is limited to the permissions requested by the configured Home Assistant integrations.

Data Storage and Usage

The application uses Google account data only to provide the configured Home Assistant functionality. OAuth credentials are stored locally in the Home Assistant installation.

This website does not collect visitor information through forms or application-specific analytics. The website is hosted by GitHub Pages, which may process technical access information.

Data Sharing

The application operator does not sell Google user data or use it for advertising. Data is exchanged with Google services as necessary for the authorized integrations.

Revoking Access

The account owner can revoke access through Google Account security settings or remove the integration from Home Assistant.
